# BGS Website

Static website for BE GROVE SOLUTIONS.

## Structure

- `*.html` - public website pages for GitHub Pages.
- `css/`, `js/`, `images/` - website assets used by the live site.
- `docs/` - working guides for product and project Google Sheets.
- `data/templates/` - CSV templates to upload into Google Sheets.
- `data/products/` - source product spreadsheets.
- `data/imports/` - raw import CSV files.
- `data/outputs/` - generated spreadsheet exports.
